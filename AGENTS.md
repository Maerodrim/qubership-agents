# AI Agent Guidelines for qubership-agents Repository

Этот документ задает правила и стандарты для AI-ассистентов при создании и модификации заметок, агентов и шаблонов в этом репозитории.

---

## 📌 Основные принципы

1. **Структурированность и чистота**:
   - Все файлы хранятся в соответствующих подкаталогах (`agents/`, `notes/`, `skills/`, `templates/`).
   - Имена файлов используют kebab-case (например, `local-setup.md`, `bdd-test-engineer.md`).

2. **Язык**:
   - Заметки и описания задач могут быть на русском или английском языке (в зависимости от контекста).
   - Технические спецификации, шаблоны PR и промпты агентов предпочтительно формулировать на английском (или двуязычно), так как целевые репозитории Qubership (`qubership-envgene`) ведутся на английском языке.

3. **Связь с целевыми репозиториями**:
   - При ссылках на код или документацию из соседних репозиториев (например, `qubership-envgene`) указывайте относительные пути или названия модулей (например, `modules/envgene/`, `cucumber_tests/`).

4. **Безопасность и секреты**:
   - **Строго запрещено** сохранять в репозиторий реальные токены, пароли, приватные ключи, креды от внутренних стендов и сред.
   - Используйте заглушки `<TOKEN>`, `<PASSWORD>`, `example.com`.

---

## 📝 Стандарты оформления заметок (`notes/`)

- Каждая заметка по задаче (`notes/tasks/`) должна содержать:
  - Цель задачи / Issue ID
  - Контекст и анализ проблемы
  - Предлагаемое решение / план действий
  - Чеклист шагов выполнения
  - Ссылки на связанные файлы / PR
- Архитектурные заметки (`notes/architecture/`) должны сопровождаться диаграммами Mermaid или текстовыми схемами потоков данных.

---

## 🤖 Стандарты описания агентов (`agents/`)

Файл агента должен содержать:
- **Role / Название роли**: Краткое определение зоны ответственности.
- **System Prompt**: Четкие инструкции по поведению, ограничениям и целям.
- **Domain Knowledge**: Специфические знания по проекту (библиотеки, соглашения, паттерны).
- **Example Workflows**: Примеры типовых запросов и ожидаемых ответов.
