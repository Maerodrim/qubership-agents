# Qubership Agents & Knowledge Base

Репозиторий для хранения конфигураций AI-агентов, промптов, навыков (skills), заметок по архитектуре и трекинга задач в рамках проектов экосистемы **Qubership** (в частности, `qubership-envgene`).

---

## 📁 Структура репозитория

```text
qubership-agents/
├── agents/             # Промпты и конфигурации специализированных AI-агентов
├── skills/             # Переиспользуемые навыки и сценарии (Skills) для агентов
├── notes/              # Заметки и база знаний
│   ├── architecture/   # Архитектурные описания модулей, схем и концепций
│   ├── guides/         # Инструкции по локальной настройке, тестированию, запуску
│   ├── tasks/          # Журнал задач, разбор issues, драфты CR и PR
│   └── cheatsheets/    # Шпаргалки по командам, git-конвенциям и чеклистам
├── templates/          # Шаблоны для задач, PR, ADR и новых агентов
├── AGENTS.md           # Правила и инструкции для AI-ассистентов в этом репозитории
└── README.md           # Описание репозитория
```

---

## 🎯 Назначение директорий

### 1. `agents/`
Хранилище системных промптов и настроек специализированных ролей:
- **`envgene-assistant.md`** — общий ассистент по разработке и модулям Envgene.
- **`bdd-test-engineer.md`** — агент для проектирования и отладки BDD (Cucumber/Gherkin) тестов.
- **`code-reviewer.md`** — агент для проверки кода в соответствии с требованиями и стандартами Qubership.

### 2. `skills/`
Специфические навыки и сценарии выполнения задач (совместимые с Antigravity / Claude Code / Cursor / CLI-инструментами):
- Генерация BDD-тестов по описанию задачи.
- Проведение аудита несоответствий (discrepancy audit).
- Оформление документации по гайдам Qubership.

### 3. `notes/`
Личные и командные заметки:
- **`architecture/`**: Описание того, как устроен `envgene`, схемы инвентаря, сборка эффективного набора, шаблонизация.
- **`guides/`**: Пошаговые инструкции (запуск тестов, настройка linters, работа с хуками безопасности `CyberFerret`).
- **`tasks/`**: Отслеживание прогресса по конкретным задачам, разборы инцидентов, фиксация промежуточных решений.
- **`cheatsheets/`**: Быстрые шпаргалки по Conventional Commits, частым командам CLI, Makefile и Git.

### 4. `templates/`
Готовые шаблоны для стандартизации работы:
- Шаблон разбора задачи/CR.
- Шаблон Pull Request.
- Шаблон описания нового AI-агента.

---

## 🚀 Как использовать

1. **Создание новой заметки по задаче**:
   - Скопируйте `templates/task-template.md` в `notes/tasks/<номер-или-название-задачи>.md`.
   - Зафиксируйте контекст, планируемые изменения и результаты.

2. **Использование промптов агентов**:
   - Подключайте промпты из папки `agents/` в системные настройки вашего AI-ассистента или используйте как контекст при старте сессии.

3. **Соблюдение конвенций**:
   - Ознакомьтесь с `notes/cheatsheets/qubership-conventions.md` для корректного оформления коммитов и взаимодействия с репозиторием `qubership-envgene`.
